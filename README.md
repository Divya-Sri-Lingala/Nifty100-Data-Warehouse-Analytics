# Nifty100 Financial Analytics Dashboard

## Overview

The Nifty100 Financial Analytics Dashboard is an end-to-end Business Intelligence project focused on analyzing the financial performance of Nifty100 companies using modern analytics and visualization tools.

This project demonstrates a complete analytics workflow starting from financial data structuring and warehouse creation to interactive dashboard development and financial insight generation.

The solution was built using PostgreSQL for data storage and Power BI for business intelligence reporting, enabling efficient analysis of profitability, debt management, and company-wise financial performance.

---

## Tech Stack

* VS Code
* PostgreSQL
* pgAdmin 4
* Power BI Desktop

---

## Project Highlights

* Built a structured financial data warehouse using PostgreSQL
* Created fact and dimension tables for efficient analytics
* Connected PostgreSQL with Power BI for interactive reporting
* Developed KPI-driven dashboards and financial visualizations
* Performed company-wise profitability and debt analysis
* Implemented professional star schema data modeling
* Designed interactive analytical dashboards for business insights
